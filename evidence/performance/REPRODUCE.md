Run only pinned, independently acquired stock tools and normal optimized RDU binaries; build public integrated source ea5969853f52770e627dfb60333194a182f9edc2 and B prototype source e591e3f1992fef70039dc5ea9b578c84d6aa3c93 in isolated checkouts if reproducing the architecture comparison. `performance.json` supplies all32 cases, seven scalar command templates plus the two B retained profiles, seed2026111057, one warmup/seven measured rounds and all numeric results.
